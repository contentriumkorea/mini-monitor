# Mini Monitor 사용 안내

## [Windows 설치파일 다운로드](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)

Windows 10/11 x64용입니다. 32비트 Windows와 ARM 전용 설치본은 제공하지 않습니다.

1. 실행 중인 Mini Monitor를 완전히 종료합니다.
2. 설치파일에서 `설치 / 갱신`을 누르고 다운로드·검증·설치 완료를 기다립니다.
3. `실행` 버튼 또는 바탕화면·시작 메뉴의 Mini Monitor를 엽니다.

바탕화면 바로가기는 기본으로 생성합니다. 설치 오류가 나면 표시된 원인을 해결한 후 다시 시도하세요. Windows 게시자 확인 경고가 나타날 수 있으므로 공식 저장소에서 받은 파일인지 확인하세요.

## 화면 제어

설정창 위쪽에서 미니 모니터·PC 오버레이·작업표시줄 바를 각각 켜거나 끕니다. USB 장치 없이 PC 표시만 사용할 수 있습니다.

- 미니 모니터는 방향·밝기를 고르고 `모니터 시작`을 누릅니다. 다른 프로그램이 같은 장치를 사용 중이면 먼저 종료하세요.
- PC 상태창은 드래그로 이동하고 크기와 배경 투명도를 조절합니다. 글자와 숫자는 투명해지지 않습니다.
- 작업표시줄 바에서는 CPU·RAM·GPU·VRAM·CODEX 중 원하는 항목과 아이콘·텍스트 표시 방식을 선택합니다. 슬라이더나 드래그로 좌우 위치를 조절합니다.
- 설정창은 작업표시줄에 표시되며 고정할 수 있습니다. 시스템 트레이 메뉴에서 창 열기와 완전 종료를 선택합니다.
- Windows 자동 실행은 설정창에서 직접 켜고 끕니다.

## Codex 계정

`ChatGPT로 로그인`에서 브라우저 인증을 진행합니다. 별도 도구 설치가 필요하지 않으며 다른 앱의 인증 자료나 로컬 사용 기록을 읽지 않습니다.

큰 퍼센트는 남은 사용 한도입니다. 크레딧 잔액은 별도로 표시하며, 한도가 실제로 소진되고 잔액이 있을 때만 `60,518 Credit`처럼 대표 수치를 전환합니다. 잔액이 없으면 `0%`를 유지합니다. 확인할 수 없는 값은 `--` 또는 `확인 불가`로 표시하며 0으로 추측하지 않습니다.

로그아웃은 Mini Monitor의 로그인만 종료합니다.

## OpenAI API 사용률

설정창의 `API 사용량 설정`에서 표시를 켜고 총액(USD), 시작일(UTC), 조직 관리자(Admin) API 키를 입력합니다. 일반 프로젝트 API 키가 아닌 비용 조회 권한이 있는 관리자 키가 필요합니다. 키는 채팅이나 문제 신고에 붙여 넣지 마세요. 이 기능은 브라우저 로그인이나 기존 브라우저 쿠키를 사용하지 않습니다.

- 총액은 직접 입력하며, 추가 충전 시 직접 변경합니다. 시작일 00:00 UTC부터 현재까지 **조직 전체** 사용금액을 공식 Costs API로 합산합니다.
- `사용률 = 사용금액 ÷ 설정 총액 × 100`입니다. 설정 총액 대비 사용률이며 실제 선불 크레딧 잔액·충전 내역을 조회하는 기능은 아닙니다. 월이 바뀌어도 자동 초기화되지 않습니다.
- 10분마다 갱신하고 수동 갱신은 최소 60초 간격입니다. 공식 집계 지연이 있을 수 있습니다. 조회 실패 시 0으로 표시하지 않습니다.
- Codex와 별도 항목으로 미니 모니터와 PC 상태창에 표시합니다. 작업표시줄에서는 `API` 항목을 선택해야 표시합니다. USB 모니터를 시작하지 않아도 조회합니다.
- 관리자 키는 Windows DPAPI로 암호화해 이 PC의 앱 전용 파일에 저장합니다. 표시를 꺼도 키는 보존합니다.

공식 문서: [Organization Costs API](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs) · [Admin API 안내](https://developers.openai.com/api/docs/guides/admin-apis)

## 업데이트·제거

설치기는 실행할 때 최신 정식 앱을 가져오며 특정 앱 버전이 고정되어 있지 않습니다. 설치된 앱은 새 버전을 알리고 사용자가 업데이트를 선택해야 적용합니다. 기본 네트워크 확인 간격은 24시간이며 수동 확인도 가능합니다.

**0.2.6 이하에서는 이전 앱의 업데이트를 다시 적용하지 마세요.** 앱을 종료한 뒤 최신 설치파일을 사용하세요. 기존 프로그램·복구 백업·로그인·설정은 먼저 삭제하지 마세요.

앱을 완전히 종료한 뒤 Windows의 설치된 앱 또는 제어판 프로그램 제거에서 Mini Monitor를 제거합니다. 프로그램 파일·등록 정보·생성한 바로가기를 정리하고 로그인과 개인 설정은 보존합니다. 설치 폴더에 개인 파일이 있거나 프로그램 파일이 수정되었다면 안전을 위해 제거가 중단될 수 있습니다.

## 호환성·지원

USB 출력은 지원 3.5인치 장치에 한합니다. 장치 식별값은 VID `1A86`, PID `5722`, 일련번호 `USB35INCHIPSV2`입니다. 다른 제품에는 전송하지 않습니다.

센서 지원 여부에 따라 온도·전력·VRAM 정보가 없을 수 있습니다. 모든 고배율 노트북·전체화면 게임에서 검증된 것은 아닙니다.

[문제 신고](https://github.com/contentriumkorea/mini-monitor/issues)에는 앱 버전, Windows 버전, 화면 배율과 재현 방법을 남겨 주세요. 계정 이메일, 토큰, 로그인 주소와 원본 진단 로그는 공개하지 마세요.
