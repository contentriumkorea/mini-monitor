# Mini Monitor 온라인 설치기

**Mini-Monitor-Setup.exe를 내려받아 실행하세요.** 약 0.5 MB의 고정 설치파일이며, 설치할 때 최신 정식 프로그램을 자동으로 내려받습니다. 인터넷 연결이 필요합니다.

- 기존 앱을 종료하고 설치 / 갱신을 누르세요. 로그인·설정·자동 실행 선택은 보존됩니다.
- 바탕화면 바로가기를 기본으로 만들고 시작 메뉴와 Windows 앱 제거 목록에 등록합니다.
- 제거 시 프로그램과 생성한 바로가기를 정리하고 로그인·개인 설정은 보존합니다.
- 서명·해시 검증 후 설치하며, 실패하면 기존 프로그램을 보존하거나 복구합니다.
- 같은 설치파일을 나중에 다시 실행해도 최신 버전을 조회합니다.
- 설치파일 자체는 Authenticode 미서명입니다. Windows에서 게시자 확인 경고가 표시될 수 있습니다.

이번 배포는 설치기 개선이며 앱 본체 0.2.11의 기능은 변경하지 않습니다. 설치기와 앱 업데이트는 별도로 유지합니다. 실제 프로그램과 변경 내역은 [최신 앱 릴리스](https://github.com/contentriumkorea/mini-monitor/releases/latest)에 있습니다. 이후에도 이 설치파일로 그때의 최신 정식 앱을 설치할 수 있습니다.
