## 사용 모습

<p align="center">
  <img src="previews/native-refresh/normal.png" alt="CPU·RAM·GPU·VRAM·CODEX 다섯 카드의 가로 화면 — 합성 수치 예시" width="720">
</p>

**한 화면에서 보는 하드웨어 상태와 남은 Codex 사용량.**

앱에서 생성한 **합성 수치 예시**입니다. 실제 계정 잔액이나 USB 화면 촬영본이 아닙니다. 상단 커버의 게이지 역시 소개용 그래픽입니다.

<details>
<summary><strong>세로 화면과 추가 사용 예시 보기</strong></summary>

<p align="center"><img src="previews/native-refresh/normal_portrait.png" alt="세로 배치 — 합성 수치 예시" width="320"></p>

USB 모니터를 시작하지 않아도 PC 상태창·작업표시줄 바의 값은 갱신됩니다. Codex 한도가 실제로 소진되고 크레딧이 남아 있으면 `60,518 Credit`처럼 잔액을 표시합니다. 잔액이 없으면 `0%`를 유지합니다.

</details>

## 설치형과 포터블, 업데이트

| 방식 | 사용 방법 |
| :--- | :--- |
| **경량 설치기** | 실행 시 최신 정식 앱을 내려받아 검증하고 설치합니다. 바탕화면 바로가기는 기본 선택되며 시작 메뉴·앱 제거 목록에 등록합니다. |
| **최신 앱 본체** | 설치기가 받는 검증된 프로그램 패키지입니다. 설치기와 앱 버전은 별도로 관리합니다. |
| **포터블 ZIP** | 같은 정식 앱의 전체 실행 폴더입니다. 설치 없이 실행하며 EXE만 따로 옮기지 마세요. 설정·로그인은 ZIP 옆이 아닌 현재 Windows 사용자의 앱 데이터 폴더에 저장됩니다. |
| **앱 업데이트** | 새 버전을 알리고 사용자가 선택하면 적용합니다. 이후 앱 업데이트마다 설치기를 다시 받을 필요는 없습니다. |

현재 앱은 **0.2.11**, 설치기는 **1.1.0**입니다. 설치기는 특정 앱 버전에 고정되지 않습니다. 로그인·설정·자동 실행 선택은 보존합니다.

## 이렇게 사용하세요

1. **PC에서 보기:** 설정창 상단에서 PC 상태창 또는 작업표시줄 바를 켭니다.
2. **USB 화면으로 보기:** 지원 장치를 연결하고 방향·밝기를 선택한 뒤 모니터 시작을 누릅니다.
3. **Codex 확인:** 앱의 ChatGPT로 로그인에서 인증합니다. 다른 앱의 인증 자료나 로컬 사용 기록은 읽지 않습니다.
4. **창 관리:** 설정창은 작업표시줄에 고정할 수 있습니다. 트레이 메뉴에서 설정 열기·완전 종료를 선택합니다.

## 적용 범위와 제한

- 지원 USB 장치와 센서에 따라 표시 가능한 정보가 다릅니다. USB 없이 PC 화면만 사용할 수도 있습니다.
- 확인되지 않는 값은 `--` 또는 확인 불가로 표시하며 0으로 추측하지 않습니다.
- 실행파일에는 Windows 게시자 코드 서명이 없어 경고가 나타날 수 있습니다. 파일 검증과 Windows 게시자 확인은 별개입니다.
- 모든 고배율 노트북·전체화면 게임 조합에서 검증된 것은 아닙니다.
- **0.2.6 이하 구버전은 기존 업데이트를 반복하지 마세요.** 앱을 종료하고 최신 설치파일을 사용하되, 기존 프로그램·복구 백업·로그인·설정을 먼저 삭제하지 마세요.
