# Corresponding source for Mini Monitor 0.2.1

Mini Monitor is distributed under GPL-3.0-or-later. The public [source repository](https://github.com/contentriumkorea/mini-monitor) and each onedir release's `source/` folder provide the preferred application source, tests, build scripts, pinned requirements, public update verification key, update helper, license information and device-protocol attribution corresponding to that release. The private Ed25519 signing key and user authentication material are neither source required to build/modify the program nor distributed.

To reproduce the Windows build, use the pinned Python/PyInstaller versions and dependency set in `requirements.lock`, verify the environment with `scripts/verify_environment.py`, and run `scripts/Build.ps1`. The build script records an input fingerprint and SHA-256 inventory; executable bytes can still depend on the host/toolchain. Source for included third-party material and the exact license inventory are documented in `THIRD_PARTY_COMPONENTS.json`, `THIRD_PARTY_NOTICES.md` and `LICENSES/MANIFEST.json`.

The application does not contain or reuse the device manufacturer's executable or DLLs. Protocol provenance is documented in `third_party/turing-smart-screen-python/SOURCE.md`. The unmodified complete pystray 0.19.5 source for upstream tag `v0.19.5` at commit `1907f8681d6d421517c63d94f425f9cdd74d0034` is included at `third_party/source/pystray-v0.19.5-1907f868-source.zip`; LGPL-3.0-or-later terms are under `LICENSES/python/pystray/`. Other native runtime materials are unmodified dependencies with source pointers, license locations and integrity hashes in the third-party inventory. No source offer is claimed for proprietary Microsoft redistributable binaries; their applicable terms are preserved in `LICENSES/runtime/CPython-3.13.3-LICENSE.txt`.

The official Codex CLI is a separate dependency, installed by the user from [OpenAI's Windows instructions](https://learn.chatgpt.com/docs/codex/cli). It is not bundled in the onedir archive or source copy.
