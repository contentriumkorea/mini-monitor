# Mini Monitor 0.3.3

설정창과 모니터링 화면의 선명도·정렬을 개선했습니다. 로컬 설치 후 확인한 패키지를 그대로 배포합니다.

- GPU는 원래의 두 팬 카드 형태, VRAM은 `V`가 있는 형태로 복원했습니다.
- 하드웨어·API 아이콘을 512px 투명 PNG로 정리하고, 기존 Codex 아이콘은 유지했습니다. API 아이콘은 달러 대신 코드 연결 형태를 사용합니다.
- 작업표시줄 `%`를 숫자 크기의 약 70%로 줄이고 하단을 맞췄습니다. 0~99%의 표시 간격은 고정하고 세 자리일 때만 늘어납니다.
- 버튼과 스위치의 거친 곡선·검은 직각 배경, 자동실행 항목 뒤의 네모 배경을 수정했습니다.
- 버튼 글자와 API 행의 중앙 정렬, 미니모니터 숫자와 `%`의 하단 정렬을 개선했습니다.
- 미리보기와 작업표시줄 글자의 가장자리를 부드럽게 처리하고, 작은 설정창에서도 밝기 슬라이더가 보이게 수정했습니다.

## 설치·업데이트

[경량 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)는 변경하지 않았습니다. 실행하면 최신 정식 앱을 내려받습니다. 기존 사용자는 앱의 **업데이트 확인**으로 적용하세요. 로그인과 설정은 유지됩니다.

이 릴리스에는 앱 ZIP·업데이트 매니페스트·서명만 포함합니다. 설치기는 위 고정 링크를 이용하세요.

## 확인 범위

실제 PC에서 설치·재실행, 계정 연결과 설정 보존을 확인했습니다. 자동 회귀 테스트 및 96~240DPI의 아이콘·배치 검사를 통과했습니다. 실제 혼합 배율 모니터 이동과 모든 OS 고대비 조합은 별도로 검증하지 않았습니다.
