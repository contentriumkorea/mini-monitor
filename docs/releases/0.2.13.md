# Mini Monitor 0.2.13

OpenAI API 사용량을 설정한 시작일 기준으로 매월 새로 집계합니다. 설정한 총액은 유지되며 남은 금액은 이월하지 않습니다. 매월 해당 날짜가 없는 경우 그 달 말일을 사용하고 다음 달에는 원래 날짜로 돌아갑니다.

초기화 시각은 UTC 00:00 (한국 시간 오전 9시)입니다. 실제 계정의 사용 기록이나 크레딧 잔액이 초기화되는 것은 아닙니다. 설정창에서 집계 시작일과 다음 초기화일을 볼 수 있습니다. 기존 설정의 시작일이 월별 기준일로 사용됩니다.

[경량 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)는 그대로이며 최신 앱을 자동으로 설치합니다. 기존 앱에서도 업데이트를 확인할 수 있습니다. 포터블은 아래 `Mini-Monitor.zip`을 전체 압축 해제해 실행하세요.

Windows 실행 파일은 Authenticode 미서명이며 패키지 업데이트 서명과는 구분됩니다.
