# Mini Monitor 0.3.4 — local validation candidate

Fix repeated settings flicker without changing data polling or output behavior.

- Live preview invalidates only its bitmap area; identical pixels schedule no repaint.
- Stable status/output captions are not sent repeatedly through native SetWindowText.
- Monitor-off discovery caption does not alternate with stopped status on each tick.
- Parent paint excludes child controls; background erase no longer flashes the flat class brush.
- The settings preview is composed offscreen and presented once, without exposing intermediate panel/background fills.
- USB updates keep disconnected changed areas separate instead of combining distant values into a screen-sized scan.
- GPU/hardware detail wrapping reserves two percentage digits so0..99% changes do not move model lines or change pagination.
- CPU/GPU model names now occupy their own full-width single line above the numeric row; long names are proportionally fitted without ellipsis, wrapping or model paging.
- OpenAI API details display TOTAL first and USED underneath; balance calculations and percentage semantics are unchanged.

Regressions were observed RED then GREEN for dirty region, unchanged frame, repeated captions, monitor-off discovery, erase behavior, offscreen painting and separated USB patches. Physical optical appearance still needs user confirmation; no public release is implied by this local fix.
