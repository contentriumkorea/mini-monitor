# Mini Monitor 0.3.4

[설치하기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe) · [포터블 ZIP](https://github.com/contentriumkorea/mini-monitor/releases/latest/download/Mini-Monitor.zip)

## 개선 사항

- 설정창과 미니 모니터 미리보기의 반복적인 깜빡임을 개선했습니다.
- USB 미니 모니터에서 숫자가 바뀔 때 불필요하게 넓은 화면을 훑어 갱신하던 문제를 개선했습니다.
- CPU·GPU 모델명은 별도의 한 줄에 전체 표시합니다. 긴 모델명은 폭에 맞춰 축소하며, 생략하거나 다음 줄로 넘기지 않습니다.
- 사용률이 한 자리에서 두 자리로 바뀌어도 상세 정보 배치가 흔들리지 않도록 했습니다.
- OpenAI API 상세 정보는 위에 TOTAL, 아래에 USED를 표시합니다. 남은 비율 계산 방식은 유지합니다.

## 설치와 업데이트

기존 사용자는 앱의 업데이트 기능을 사용하세요. 새로 설치하는 경우에는 위의 경량 설치기를 실행하면 최신 버전을 자동으로 내려받습니다. 로그인·설정·자동 실행 선택은 보존합니다.

설치기는 기존 파일을 그대로 사용하며, 이번 릴리스에는 프로그램 ZIP과 서명된 업데이트 정보만 제공합니다.
