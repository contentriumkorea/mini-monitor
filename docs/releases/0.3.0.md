# Mini Monitor 0.3.0

[설치하기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe) · [포터블 ZIP](https://github.com/contentriumkorea/mini-monitor/releases/download/v0.3.0/Mini-Monitor.zip)

- 모니터링과 설정 화면을 가볍게 정비했습니다. USB 모니터를 끈 상태에서도 PC 상태창과 작업표시줄 바를 사용할 수 있습니다.
- 작업표시줄의 1~2자리 퍼센트 간격을 고정하고, 전체화면에서는 바가 숨도록 처리했습니다. 표시할 항목·아이콘/텍스트·좌우 위치를 설정할 수 있습니다.
- OpenAI API는 남은 예산 비율을 소수점 없이 표시합니다. 총액·사용금액과 매월 시작일 기준 집계는 유지됩니다.
- Codex 로그인, 사용 한도·크레딧, 화면 방향·밝기, 투명 배경 상태창, 시작 시 실행과 트레이 기능을 통합했습니다. 기존 설정과 앱 전용 로그인은 유지합니다.
- 업데이트 적용 시 시작 확인과 복구 검증을 강화하고, 잠깐 남는 파일 잠금에 대한 복구 처리를 보완했습니다. 정상 업데이트 후 확인된 이전 파일만 자동 정리합니다.

설치기는 약 474 KB의 기존 경량 온라인 설치기를 그대로 사용합니다. 설치할 때 최신 정식 본체를 내려받습니다. 기존 앱은 완전히 종료한 뒤 설치하세요. 포터블은 ZIP 전체를 풀고 `Mini-Monitor.exe`를 실행하세요.

현재 PC에서 실제 USB 갱신, 기존 계정 연결, 바 드래그·커서, 전체화면 숨김/복귀, 서명 검증과 정상 교체/실패 복원을 확인했습니다. 장시간 연속 사용, 실제 고배율·혼합 배율, AMD/Intel 실장비는 추가 검증이 필요합니다. 확인할 수 없는 센서는 `--`로 표시합니다. Windows 보안 경고가 표시될 수 있는 미서명 실행 파일입니다.
