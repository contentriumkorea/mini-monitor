# Mini Monitor 0.2.12

OpenAI API 사용금액을 Codex와 별도로 확인할 수 있습니다.

- 설정창의 **API 사용량 설정**에서 총액(USD)과 시작일(UTC)을 직접 입력합니다.
- 조직 **Admin API 키**로 공식 사용금액을 자동 조회해 총액·사용금액·사용률을 표시합니다. 일반 프로젝트 키와는 다릅니다.
- 10분마다 자동 갱신하며 미니 모니터를 시작하지 않아도 조회합니다. 작업표시줄에는 API 항목을 선택해 표시할 수 있습니다.
- 브라우저 로그인이나 쿠키를 사용하지 않습니다. 키는 이 PC의 앱 전용 암호화 파일에 보관합니다.

설정 총액 대비 사용률이며 실제 충전 잔액·충전 내역 조회가 아닙니다. 공식 집계에는 지연이 있을 수 있습니다. 추가 충전 시 총액은 직접 변경해 주세요. 확인하지 못한 값은 0으로 추측하지 않습니다.

## 설치·업데이트

[경량 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)를 실행하면 최신 앱을 설치합니다. 기존 앱의 업데이트 버튼으로도 적용할 수 있습니다. 로그인·설정은 유지됩니다.

설치기는 변경하지 않았으며 이 릴리스에는 앱 ZIP과 서명된 업데이트 정보만 제공합니다. 설치 없이 사용하려면 아래 `Mini-Monitor.zip` 전체를 압축 해제하고 실행하세요.

실제 계정 비용 조회는 사용자가 관리자 키를 설정한 뒤 확인해야 합니다. 키를 채팅·이슈에 올리지 마세요. Windows 실행 파일은 Authenticode 미서명이며, 업데이트 패키지 무결성 서명과는 구분됩니다.
