# Mini Monitor 0.2.11

- 작업표시줄 바 드래그 입력을 Windows 콜백 밖에서 처리하고, 연속 이동을 묶어서 적용합니다.
- 바를 숨기거나 위치를 직접 바꾼 뒤 이전 드래그가 적용되는 문제를 방지합니다.
- 새 센서값·계정 정보·연결 상태가 있을 때 화면을 갱신해 CPU와 메모리 할당 부하를 줄입니다.
- 동일한 오버레이·설정 미리보기·트레이 메뉴의 불필요한 재생성을 줄입니다.
- Windows 자동 실행 항목이 없는 PC에서도 업데이트 후 구버전 정리가 정상 진행됩니다. 자동 실행 설정을 임의로 켜지 않습니다.

## 설치와 업데이트

기존 사용자는 앱의 업데이트 기능을 사용하세요.
처음 설치할 때는 [고정 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v1/Mini-Monitor-Setup.exe)를 사용하세요.
설치기는 최신 서명된 앱 버전을 자동으로 가져옵니다. 이번 릴리스는 앱 업데이트 ZIP과 서명 메타데이터만 포함하며 설치기를 재배포하지 않습니다.

센서 수집 주기는 유지됩니다. 불필요한 프레임 생성을 줄이기 위해 센서 갱신 사이의 게이지 보간 애니메이션은 생략합니다.
