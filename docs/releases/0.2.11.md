# Mini Monitor 0.2.11

- 작업표시줄 바를 드래그할 때 앱이 종료되는 문제를 수정했습니다.
- 바를 숨기거나 위치를 직접 바꾼 뒤 이전 드래그가 적용되는 문제를 방지합니다.
- 표시 내용이 같을 때 불필요한 화면 처리를 줄였습니다. 전체 앱의 CPU 사용량이 크게 감소했다고 확인된 것은 아닙니다.
- PC 상태창·설정 미리보기·트레이 메뉴의 중복 갱신을 줄였습니다.
- Windows 자동 실행 항목이 없는 PC에서도 업데이트 후 구버전 정리가 정상 진행됩니다. 자동 실행 설정을 임의로 켜지 않습니다.

## 설치와 업데이트

기존 사용자는 앱의 업데이트 기능을 사용하세요.
처음 설치할 때는 [경량 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)를 사용하세요. 설치 없이 사용하려면 [포터블 ZIP](https://github.com/contentriumkorea/mini-monitor/releases/download/v0.2.11/Mini-Monitor.zip)을 받아 폴더 전체를 압축 해제하세요.
설치기는 최신 정식 앱을 자동으로 내려받고 검증합니다. 설치기와 앱 업데이트는 별도로 배포합니다. 포터블은 폴더 전체를 유지해야 하며 설정·로그인은 현재 Windows 사용자의 앱 데이터 폴더에 저장됩니다.

센서 수집 주기는 유지됩니다. 게이지는 새 측정값을 받을 때 갱신합니다.

이번 배포 페이지 정리는 앱 기능 변경이 아닙니다. 앱은 0.2.11, 설치기는 1.1.0을 유지하며 이미 최신 앱을 쓰고 있다면 다시 설치할 필요가 없습니다.
