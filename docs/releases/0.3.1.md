# Mini Monitor 0.3.1

설정창을 차콜·그레이 스모크 글라스 스타일로 정돈했습니다. 글자는 선명하게 유지하고, 지속적인 배경 블러나 애니메이션은 사용하지 않습니다.

- 상단에서 미니 모니터·PC 상태창·작업표시줄 바를 한곳에서 켜고 끕니다.
- 연결·Codex·OpenAI API 설정을 묶고 미리보기와 하단 실행 버튼을 분리했습니다.
- PC 상태창·작업표시줄·API 보조 설정창에도 같은 스타일을 적용했습니다.
- 작은 작업 영역에서 세로 간격을 압축하고, 배율에 맞춰 최초 창 크기를 제한합니다.
- 체크·선택·키보드 조작과 비밀번호 마스킹을 유지하고 고대비 색상 대응을 보강했습니다.

## 설치 및 업데이트

[경량 온라인 설치기](https://github.com/contentriumkorea/mini-monitor/releases/download/installer-v2/Mini-Monitor-Setup.exe)는 변경하지 않았습니다. 실행하면 최신 정식 버전을 내려받습니다.
기존 사용자는 앱의 **업데이트 확인**을 사용하세요. 이 릴리스의 ZIP·매니페스트·서명은 자동 업데이트용이며, 새 설치는 위 설치기를 이용하면 됩니다.

## 확인 범위

네이티브 컨트롤·배율·배치·그래픽 자원 회귀 테스트와 비활성 미리보기 화면을 확인했습니다. 실제 혼합 배율 모니터 이동, 고대비 OS 설정 전환 및 물리 키보드·마우스 조작은 이번 배포에서 별도로 재검증하지 않았습니다. 기존 계정·설정 및 모니터링 계산 방식은 변경하지 않았습니다.
